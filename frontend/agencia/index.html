Medios para publicar

Subir archivo

Subí una o varias imágenes/videos directo a Cloudflare R2 (mantené Ctrl o Shift apretado para elegir varios archivos del explorador a la vez). Se guardan en la carpeta del cliente elegido arriba en el selector, y te dan la URL pública lista para pegar en la pestaña "Medios" (o para armar un carrusel de una).

Imágenes: jpg, jpeg, png, webp (máx. 15MB c/u). Videos: mp4, mov (máx. 100MB c/u).

Archivos en Host

Todo lo que ya está guardado en Hostinger para el cliente elegido arriba en el selector. Se puede copiar la URL, usarla en "Medios" o eliminar el archivo del servidor.

Nuevo cliente

Conectar cuenta de Facebook / Instagram Opcional, podés cargarla ahora o más tarde desde "Editar cliente". Generá el Page Access Token de larga duración en Graph API Explorer (ver README).

🎬 Guion para cámara —

Plantilla de 30-45 segundos para ayudar al comerciante que no sabe qué decir frente a la cámara. Se le puede pasar así, solo llena los espacios entre corchetes con su realidad. Editable antes de copiar.

Editar cliente

Conectar cuenta de Facebook / Instagram Generá el Page Access Token de larga duración en Graph API Explorer (ver README).
⭐ Monitoreo de reseñas de Google (opcional) Buscá el negocio en el buscador de Place ID de Google y pegá acá el ID. Las reseñas de Facebook no necesitan nada extra: se leen con el mismo Page Access Token de arriba.

Eliminar cliente

Vas a eliminar a y todos sus datos (posts, cuentas conectadas, leads, métricas, etc). Esta acción no se puede deshacer.
